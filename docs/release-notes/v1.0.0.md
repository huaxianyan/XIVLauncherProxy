首次发布。为 XIVLauncher 提供按快捷方式启用的本地代理，只向 XIVLauncher 及其子进程注入代理环境变量，不修改用户或系统的全局设置。

## 新功能

- **本地代理启动器**：填写代理地址后，程序在自身目录生成 `XIVLauncherProxy.lnk`，以后通过该快捷方式启动 XIVLauncher 时自动带上代理环境变量。
- **代理设置界面**：提供程序路径选择、代理地址输入和「测试连接」，可在保存前确认代理端口正在监听。
- **可选的全局变量**：可以同时设置 `ALL_PROXY`，或让本地地址直接连接而不经过代理。
- **配置持久化**：设置保存在 `%LocalAppData%\XIVLauncherProxy\config.json`，带 `--launch` 参数运行时直接读取该配置启动。

使用方式与构建命令见 [README](https://github.com/huaxianyan/XIVLauncherProxy/blob/v1.0.0/README.md)。
