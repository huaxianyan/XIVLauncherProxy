只用 HTTP 和 HTTPS 时可以直接填写完整地址，但要用 SOCKS4 或 SOCKS5 就只能自己手写协议头，容易写错又不便核对。这一版把协议独立成下拉选择，地址与端口分开填写。

## 新功能

- **代理协议可选**：新增 SOCKS4 和 SOCKS5，与原有的 HTTP、HTTPS 一起放在协议下拉框中。
- **地址与端口分开填写**：协议单独选择，地址框只填 `127.0.0.1:37777` 这类内容，界面会按所选协议拼出完整代理地址。
- **已有配置继续可用**：打开旧配置时会自动识别并拆分已保存的代理地址，重新选择对应协议。

使用方式见 [README](https://github.com/huaxianyan/XIVLauncherProxy/blob/v1.1.0/README.md)。
