可以直接导入身份验证器导出的二维码，不再需要手动抄写 TOTP 密钥。同时补齐了启用代理和快捷登录前的配置检查。

## 新功能

- **二维码导入**：点击「导入二维码」选择身份验证器导出的图片，自动填入对应账号的密钥。支持 PNG、JPEG、BMP、GIF 和 WebP。
- **Google Authenticator 导出格式**：支持其私有的 `otpauth-migration://` 导出数据，包括一个二维码含多个账号、以及大批量导出拆成多张二维码的情况。多张图片可一次全选，解析出的账号会合并后供选择。
- **二维码只在本机解析**：图片在本地离线识别，不上传网络，也不复制到配置目录，只保存选中的密钥。

## 问题修复

- **未配置代理时仍可勾选代理**：启用代理前会先检查代理地址，未填写或格式无效时不再允许勾选，并提示先完成基础设置。
- **未配置 XIVLauncher 路径时功能仍可启用**：启用代理或快捷登录前会先确认 `XIVLauncher.exe` 路径有效，路径为空、文件不存在或选错文件时不再允许启用，并提示先选择正确路径。已经启用后改坏路径或代理地址，对应开关会自动取消。

使用方式见 [README](https://github.com/huaxianyan/XIVLauncherProxy/blob/v3.1.0/README.md) 的「使用」一节。
