修正了 XIVLauncher 自身登录失败时误弹配置窗口的问题，并更新了二维码解码所使用的图像库。

## 问题修复

- **XIVLauncher 登录失败时误弹配置界面**：快捷方式启动后，登录结果已由 XIVLauncher 掌握。此前只要验证码提交阶段出错，配置界面就会弹出，看起来像是本软件的问题。现在这类失败改为静默退出并写入 `%LocalAppData%\XIVLauncherProxy\launch.log`，XIVLauncher 自己的提示保持为唯一的用户提示。日志只记录时间、错误代码和启动配置 ID，不含密钥、验证码或账号名。
- **等待超时后无声退出无迹可查**：XIVLauncher 始终没有请求验证码时同样会记录，便于事后确认是 XIVLauncher 未走到验证码这一步。

属于本软件或配置的问题仍然会打开配置界面并给出对应提示，例如启动配置已被删除、账号尚未保存密钥、XIVLauncher 路径无效或进程无法启动。

## 改进

- **二维码解码改用 SkiaSharp**：原先依赖的 ImageSharp 2.x 被报告存在 TIFF 编码器越界写等问题，改用 SkiaSharp 后不再引入这类告警，二维码导入功能不变。

诊断日志的记录内容见 [README](https://github.com/huaxianyan/XIVLauncherProxy/blob/v3.3.0/README.md#%E5%90%AF%E5%8A%A8%E8%AF%8A%E6%96%AD%E6%97%A5%E5%BF%97)。
