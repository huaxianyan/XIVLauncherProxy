从只做代理的启动器重写为同时提供代理和自动 OTP 登录的配置程序。旧版只能把代理交给 XIVLauncher，登录仍要手动输入验证码；这一版可以按账号生成独立快捷方式，一键完成代理和登录。

## 新功能

- **自动 OTP 登录**：等待 XIVLauncher 请求验证码后自动生成并提交，完成后恢复启动前 XIVLauncher 的自动登录设置。
- **启动配置**：每个配置可以只启用代理、只启用快捷登录，或同时启用两者。只启用代理时停留在账号选择界面，便于手动挑选账号。
- **多账号支持**：可以为多个账号分别保存 TOTP 密钥并各自生成独立快捷方式；一键登录通过 `--account` 明确指定账号，避免多账号下登录到错误账号。
- **TOTP 密钥导入**：支持 Base32 密钥和 `otpauth://` 地址，也接受带空格、连字符或填充符 `=` 的写法。
- **加密保存密钥**：TOTP 密钥使用 Windows DPAPI `CurrentUser` 加密，保存在单独的 `totp-credentials.json`，不写入普通配置、日志或快捷方式。
- **界面重写**：改用 Avalonia UI 与 MVVM，界面提供基础设置与启动配置两个页面，并支持浅色蓝色主题。

## 问题修复

- **验证码提交过早结束**：旧实现依赖入口进程存活来判断是否继续，XIVLauncher 转交给自己后会导致提交提前中止；现在以经过身份验证的本地 OTP 服务为准。
- **误提交到其他程序**：提交前会确认 `127.0.0.1:4646` 返回的 `app` 为 `XIVLauncher`，避免把验证码发给占用该端口的其他程序。

密钥的保护方式、安全边界和已知风险见 [README](https://github.com/huaxianyan/XIVLauncherProxy/blob/v3.0.0/README.md#totp-%E5%AF%86%E9%92%A5%E5%A6%82%E4%BD%95%E4%BF%9D%E5%AD%98)。

安装包改为 .NET 10 自包含单文件发布，不再需要预先安装对应版本的 .NET Runtime。本软件不提供 Square Enix OTP 的申请、绑定、解绑或迁移，请先通过官方流程完成绑定。
