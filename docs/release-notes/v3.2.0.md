此前更新只能手动到 GitHub 下载替换，而且代理地址要自己手写协议头。这一版加入了内置自动更新，并把代理设置拆成协议、地址和端口三个字段。

## 新功能

- **自动更新**：启动时检查 GitHub 最新正式 Release，也可以手动检查。发现新版本后可下载并安装，界面显示已下载大小、总大小和百分比。
- **代理协议可选**：代理设置改为协议下拉框加地址、端口输入框，支持 HTTP、HTTPS、SOCKS4 和 SOCKS5；已有配置中的代理地址会自动识别并拆分。
- **更新走代理**：可以用「软件更新使用此代理」让检查和下载更新复用同一个代理，关闭后更新恢复直接连接，不影响启动配置的代理行为。
- **安全替换与回滚**：更新只接受 Release 中名称固定的 `XIVLauncherProxy.exe` 与对应 `.sha256`，下载后校验 SHA-256，再由临时更新进程替换程序并自动重启；替换失败或新版本未能持续启动时恢复原版本。

自动安装支持 Windows 自包含单文件正式版，目标位置为当前运行的 `XIVLauncherProxy.exe`，只要目录有写入权限即可原地更新。开发构建仍可检查更新，但不会替换自身。

更新流程与支持范围见 [README](https://github.com/huaxianyan/XIVLauncherProxy/blob/v3.2.0/README.md#%E8%BD%AF%E4%BB%B6%E6%9B%B4%E6%96%B0)。
